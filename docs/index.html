Set up in three steps

The launcher works on its own. Game Mode also needs a Windows gaming PC, so get that ready first.

  1. Prepare your PC (Game Mode only)Install Apollo, then run pc/setup.ps1 once. It adds Game Mode, opens the firewall for your home network and finds your Steam, Epic, Xbox, GOG and Ubisoft games.
  2. Install on the TVTurn on Wireless debugging, then run .\install-tv.ps1 -Tv <ip:port> from the README. It installs and sets everything up.
  3. Follow the wizardBruce TV opens a short setup wizard on the TV: pick a layout, install Moonlight, find and pair your PC. About a minute.
