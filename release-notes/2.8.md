Playnite
- Game Mode can now open Playnite instead of the Bruce Game Mode menu: Control Center > Game Mode app > 3rd party · Playnite
- Bruce finds Playnite on your PC by itself; to pick its folder, open Game Mode > Menu > Settings > Playnite
- Nothing to set up again on the PC, and it works with your existing Game Mode entry in Apollo or Sunshine

Display
- Backlight, Color and Contrast are now one "Display" panel with sliders

Icons
- "Icon size" is now "Icons": a size slider with a live preview of the Bruce TV tile at that size
- New switch to show or hide an app's name when it is focused on Home

Fixes
- The daily wallpaper now retries by itself when the download fails (for example while the TV's network is still waking up), instead of staying on yesterday's photo
